# 工程控制论（钱学森，1954）

序言的宗旨：把工程实践中反复使用的设计原则和实验方法整理出来，抽出共性、上升为理论，让工程师用更系统的眼光看技术问题，再指导不同领域的实践。所以这不是控制数学手册，而是一套**面对受控系统的固定动作，以及每个动作该调的工具**。

全书的顺序本身就是方法论：**先判稳，再谈快慢；先定结构，再调参数；先覆盖不确定性，再验收**。稳定是约束，不是指标。

> 章节号对应 1954 英文版 / 1958 中译本的 18 章结构。以下为方法论提炼；要推公式、查原话时回去翻书。

## 1. 确认这是不是一个控制问题

四要素：**目标**（跟踪什么）、**对象**（有惯性、延迟、非线性）、**量测**（输出可观测）、**执行**（输入可改变）。

缺一项先补一项：缺量测 → 先解决观测，没观测的闭环是猜；缺执行 → 是资源或权限问题，不是控制问题；目标写不成指标 → 退回定性讨论（见第 8 节）。

**完成判据**：一句话写出「通过调节 X，使 Y 跟踪 Z，同时抵抗 W」，再把它扩成指标卡：

```text
目标量 ____，设定值/跟踪信号 ____
超调 ≤ ____，调节时间 ≤ ____，稳态误差 ≤ ____，带宽 ≥ ____
对 ____ 扰动的恢复时间 ≤ ____
约束：执行器行程/速率上限 ____，可测变量 ____，已知延迟 ____
```

指标写不出数字，说明还没到能设计的程度——先补测量。

## 2. 建模：选能解释现象的最低层级

书里的做法是用传递函数描述对象，只保留「输入→输出」的对外行为，不管内部物理细节。正因如此，机械、电气、液压系统落在同一个数学层面上，设计原则才能跨领域迁移——这是「共性抽象」的技术基础。

| 层级 | 描述 | 何时够用 |
| 黑箱 | 阶跃/频率响应曲线 | 内部不可知，只能测 |
| 灰箱 | 一阶/二阶 + 纯延迟（K, T, τ） | 工程上绝大多数对象 |
| 白箱 | 状态方程 | 要预测没测过的工况 |
| 随机 | 功率谱、相关函数 | 输入是噪声 |
| 离散 | 采样周期 + Z 变换 | 数字控制、按拍执行 |

模型只在**你关心的频段和时标**上需要准。低频不准会漏掉稳态误差，高频过度建模是浪费。频率响应是这套方法的通用语言：同一张 Bode 图既用来估模型，也用来读稳定裕度。

**完成判据**：模型至少复现一个实测现象——阶跃响应形状、振荡周期、纯延迟时长。

## 3. 判稳：稳定性先于性能

- 线性定常：Routh–Hurwitz 判根、Nyquist 判频域、根轨迹看参数走向
- 含纯延迟：用 Nyquist。延迟 τ 在穿越频率 ω_c 处偷走 ω_c·τ 弧度相位——「调好了，加个网络、加个构建步骤就振」多半是它
- 非线性（继电器、饱和、死区）：描述函数预测极限环
- 时变或大范围变化：Lyapunov 直接法

工程裕度口径：相位裕度 30°–60°，增益裕度 ≥ 6 dB。

诊断时先查这张表，再决定动哪个旋钮：

| 症状 | 多半是 | 先动哪个 |
| 等幅或发散振荡 | 相位不足：增益高、延迟大 | 降增益、加超前、减延迟 |
| 超调大、回调慢 | 相位裕度不够 | 超前校正、降增益 |
| 迟钝、跟不上 | 带宽不足 | 提增益或加超前，同时看噪声 |
| 总是差一点 | 低频增益不足、无积分 | 加积分、提高型别 |
| 高频抖动、执行器发热 | 带宽盖过噪声频段 | 加低通、降带宽 |
| 时好时坏地失稳 | 延迟随负载变（排队） | 降 ω_c、留延迟裕度 |

**完成判据**：给出裕度的数字，并指出裕度被谁吃掉——延迟、惯性、饱和，还是采样。

## 4. 定结构：先问该不该闭环

- 开环/前馈：扰动可测、对象本身稳定 → 更简单，不引入失稳风险
- 闭环：对象不稳、参数漂移、扰动不可测 → 必须反馈
- 复合：前馈抗可测扰动 + 反馈抗不可测偏差 + 校正环节改频率形状
- 多回路互相串扰：先解耦（Ch.5 不互相影响的控制），把回路拆开再各自设计

| 要解决的问题 | 结构对策 |
| 稳态误差 | 加积分、提高低频增益 |
| 扰动可测但来得快 | 前馈，不等反馈 |
| 对象增益漂移大 | 加深反馈，用低增益换鲁棒 |
| 既要跟得快又要不抖 | 两自由度：跟踪与抗扰分开设计 |

**完成判据**：画出信号流图（参考→误差→控制器→对象→输出→反馈），标出每个扰动的注入点。

## 5. 配指标：没有免费的快速性

三个指标互相拉扯：**快速性（带宽）、稳定性（裕度）、抗噪性（高频增益）**。加增益：误差变小、裕度变差、噪声放大。Bode 灵敏度积分（水床效应）说明：某频段压下去，必在另一频段翘起来。

按频段分工定指标：**低频**管稳态精度，**中频**管稳定裕度与响应速度，**高频**管抗噪与未建模动态。

设计动作是先定「哪段频率、哪段时间最重要」，再明确**放弃哪一项**。

**完成判据**：写下放弃的那一项，以及为什么可以放弃。

## 6. 覆盖不确定性：每类都有对应工具

| 情形 | 书里（章） | 现代对应 |
| 纯延迟 | Ch.8 时滞系统 | Smith 预估、降带宽 |
| 继电器、饱和、摩擦 | Ch.10 继电器伺服、Ch.11 非线性 | 抗饱和、极限环抑制 |
| 随机输入 | Ch.9 平稳随机输入、Ch.16 噪声过滤设计 | 维纳/卡尔曼滤波、按信噪比分带宽 |
| 参数时变 | Ch.12 时变线性系统、Ch.13 用扰动理论设计 | 增益调度、短时冻结分段线性 |
| 参数大范围不可预测 | Ch.17 自镇定与环境自适应 | 模型参考自适应、鲁棒控制 |
| 指标给定、模型粗糙 | Ch.14 满足指定积分条件的设计、Ch.15 自动寻优 | 最优控制、极值搜索 |

**完成判据**：列出「模型没覆盖的情形」，逐条写失效模式和兜底动作。

## 7. 误差与可靠性

误差控制（Ch.18）把精度当成独立设计目标：先把总误差拆成来源——模型误差、扰动、量测噪声、执行饱和、离散化——再逐项分配抑制手段，而不是笼统「调准一点」。

可靠性靠结构：冗余加表决；允许单点出错、靠闭环纠正；大系统分解为子系统加协调层（这一条后来长成钱学森的系统工程与「总体设计部」）。

**完成判据**：指出系统里最不可靠的一环，以及用哪种结构吸收它。

## 8. 验证，以及迁移边界

验收顺序：时域（超调、上升时间、调节时间、稳态误差）→ 频域（裕度、带宽）→ 最坏情形（参数取边界、最大扰动、执行饱和）→ 上线小步试运行，盯未建模的振荡。

**完成判据**：每条指标有实测数字；最坏情形不失效。

### 迁移到非工程闭环

只要目标可写成指标、输出可测、手段可调、有惯性和延迟，这套动作就适用——agent 循环、调度器、运维流程都算。先确认误差信号真实存在，再用这张对照表：

| 控制概念 | 对应物 |
| 参考输入 | 需求、验收标准 |
| 误差信号 | 测试失败、指标偏差、用户投诉 |
| 执行器 | 工具调用、部署、改配置 |
| 被控对象 | 代码库、集群、业务流程 |
| 扰动 | 上游变更、流量波动、依赖故障 |
| 时滞 | 构建、部署、反馈的延迟 |

失效模式照搬第 3 节的症状表，只把对象换成人：**超调** = 一次改动过大；**越调越乱** = 反馈延迟长而人手动增益高，缩小步长、缩短反馈周期；**迟钝** = 反馈周期太长，人拿不到及时信号。

**不适用**：目标本身会变、参与者有自主意志、系统开放到划不清边界。钱学森后期用「从定性到定量综合集成法」处理这类开放复杂巨系统，那是另一套方法，本技能不覆盖。类比必须落到可测的误差信号上，落不到就退回定性讨论。

## 元原则

1. **工程科学方法**：物理直觉 → 数学表述 → 求解 → 实验验证。数学服务工程判断，不为漂亮而漂亮（Ch.2–3 把 Laplace、Bode、Nyquist 当工具用，就是这个态度）。
2. **共性抽象**：从一处提炼的原则，要能拿去指导另一处——这是检验它配不配叫「原则」的标准。
3. **整体优先**：先划系统边界、看它与环境的交换，再拆子系统；拆之前先问每个子系统对外的输入输出是什么。
